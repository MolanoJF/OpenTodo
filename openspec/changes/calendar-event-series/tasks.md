# Tasks

Groups 1, 2 and 3 are Go; groups 4 and 5 are web; **the Go chain (1 to 3) and the web chain (4 and 5) are independent** and can be built in parallel by two agents against the REST contract in design D3 and the types in D11 (a web agent uses a fake `api` in vitest, a Go agent never touches `web/`). Within the Go chain, 1.x (the pure engine) and 2.1 to 2.2 (the store and the interface) can also run in parallel; 2.3 to 2.6 need 1.x. Group 6 needs 1 to 3. Group 7 comes last. Run `make check` before ticking 7.7.

Verify backend tasks with `go test ./...` (or the named package) and frontend tasks with `npm test` and `npm run build` in `web/`. Phases 1 and 2 (`calendar-event-edits`, `calendar-event-editor`) are the base branch: do not change their behaviour for single events.
