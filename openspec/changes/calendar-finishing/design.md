# Design
Use a 12% sunken/canvas mix for weekends instead of 45%. Disable IconButton tooltips in preview headers; keep aria-labels. Reuse PreviewFact for icon-led page fields while preserving field labels and existing controlled form behavior.

Calendar moves compose existing authenticated create/delete endpoints for single, writable, deletable events without guests, conferencing, custom/unsupported reminders or formatted descriptions. Require loaded plain description and reminders, no pending source writes, a writable target that supports its reminders, and an online device. Freeze the draft once a move begins. Before the first request persist a device meta receipt containing source revision, target and one client ID. Creation is retried with that client ID. Persist its result before deleting the original with its original revision. On failure retain the original and receipt, and offer Finish move; never automatically delete the destination copy. A reload resumes the same receipt. A successful local transaction adopts the destination and removes the original and receipt. This is not an offline queued move; ordinary edits keep their existing outbox and convergence behavior. No synced entity changes or new routes.

If a confirmed copy exists and the source cannot be removed, offer Keep both events to clear the receipt without changing either remote calendar. Refused creation clears its receipt; uncertain creation retains the same client ID for retry. No dependency or extra screen chrome/scroll regions. No new shortcuts or sidebar items. Keep within the existing bundle budget and verify provider failures with fakes; do not move real user events during deployment verification.
