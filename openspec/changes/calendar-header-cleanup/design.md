# Design
Reuse the shared Menu, MenuItem, Button and device-storage primitives. Retain existing routes and scheduling precision: a device-local day count customizes the Week route, anchored at its date for 2–6 days; normal Week resets it to seven and honors the preferred week start. Navigation and keyboard paging advance by the visible day count. The dropdown has a keyboard-accessible Number of days step and all existing modes. Visibility controls live in each mode's overflow at all widths. Empty lane drop targets remain available without a dashed placeholder; reveal them during lane drags. All-day events, deadlines, spans and date-only tasks remain visible. Remove only visible Day/Week capacity summaries, not task estimates or scheduling functionality. Use existing theme tokens; no dependencies, API or data migration. Verify responsive layout, empty/populated lanes, navigation and menu persistence. Keep existing bundle budgets.

Measured build: 143.4 KB entry / 692.6 KB first load, within unchanged budgets; first load grew about 0.5 KB against the prior mobile build. No new dependencies.
