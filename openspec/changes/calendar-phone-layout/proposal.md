# Why
Phone calendar controls consume a second row, reserved add-button padding leaves a blank strip below the grid, and the event editor shows too many boxed fields at once. Match the supplied mobile references while retaining the current editing and recovery behavior.

# What
Place calendar range/navigation beside a compact title, let the calendar extend beneath its floating add button, and use compact event rows with expandable schedule and optional fields. Put the event submit action in the phone header and remove the contrasting footer background. Keep desktop layouts and existing event validation, permissions, dirty-close protection and provider confirmations.
