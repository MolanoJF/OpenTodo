# Tasks

Groups 1, 2 and 3 are Go; groups 4 and 5 are web; **the Go chain (1 to 3) and the web chain (4 and 5) are independent** and can be built in parallel by two agents against the REST contract in design D3 and the types in D11 (a web agent uses a fake `api` in vitest, a Go agent never touches `web/`). Within the Go chain, 1.1 to 1.4 (the pure engine) and 1.5 (the store) can run in parallel; group 2 needs group 1; group 3 needs 2. Group 6 needs 1 to 3. Group 7 comes last. Run `make check` before ticking 7.6.

Verify backend tasks with `go test ./...` (or the named package) and frontend tasks with `npm test` and `npm run build` in `web/`. Phases 1 to 3 (`calendar-event-edits`, `calendar-event-editor`, `calendar-event-series`) are the base branch: do not change their behaviour for events without guests. **Nothing in this change may write a message to a person unless a test names the message and the confirmation that allowed it** (design D8, D18).
